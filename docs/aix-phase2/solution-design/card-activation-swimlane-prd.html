AIX Card 7.2.1 实体卡激活流程

产品需求说明（PRD）— 跨角色泳道视图

文档类型
PRD / 流程泳道图
版本
7.2.1
范围
实体卡激活主路径、校验分支与结果分流
流程摘要（与上图一致）： 用户进入 Card Manage / 激活入口后输入实体卡后 4 位；App 自动提交并请求 Inquiry Card Basic Info；后端校验后 4 位，不匹配则错误提示并回到输入；匹配则进入 Set PIN → Confirm PIN，不一致则 Toast 并回到 Set PIN；一致则拉起 AAI，认证通过后调用 Card Activation，并按结果分别进入成功（Card Home）或 Active Fail / Set Fail / Network Error / Server Error 等页面。
本文档为 AIX Card 7.2.1 实体卡激活泳道示意，供评审与实现对齐使用；细节字段与接口契约以接口文档与 UI 稿为准。

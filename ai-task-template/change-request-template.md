# Change Request Template

> 当中途需要修改任务目标、范围、输出物、阶段、任务或上下文时，必须创建 Change Request。
> 不能直接改任务继续执行。

---

# 1. 变更处理流程

```text
提出变更
→ 记录变更
→ 评估影响
→ 更新 Task Ledger 建议
→ 等待用户确认
→ 确认后继续执行
```

# 3. 新增独立任务强制规则

如果变更符合以下任一情况，倾向于判断为独立新任务：

1. 目标与当前任务无明显依赖关系
2. 输出物完全不同
3. 需要一套新的上下文材料
4. 当前任务完成与否不影响新任务开始
5. 用户表达的是另一个新的工作事项

但即使判断为独立新任务，也不能直接新建。

必须先问用户：

```text
这看起来是一个独立新任务。是否确认新开一个任务台账？
```

用户确认后，才能新开。

---

# 4. 当前台账内追加任务规则

如果变更符合以下情况，可以在当前 Task Ledger 里追加阶段或任务：

1. 是当前任务的延伸
2. 使用同一批上下文
3. 目标仍服务于同一个最终输出
4. 只是增加检查、补充、审核、交付格式
5. 不改变主任务边界

但如果影响关键范围或最终输出，仍需用户确认。

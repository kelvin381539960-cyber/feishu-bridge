# AI 通用任务执行台账模板 v1.0

这是一个用于让 GPT / Agent 稳定执行复杂任务的通用模板。

它不是产品专用模板。适用于：

- 产品方案
- PRD / 文档写作
- 知识库整理
- 代码分析
- 技术方案
- 行业调研
- 项目推进
- 数据分析
- 任意复杂多步骤任务

## 核心原则

1. `task-ledger-template.md` 是唯一真相。
2. 所有任务必须拆成阶段、任务、Agent、上下文、输出物、完成标准。
3. 每一步执行后必须回填 Task Ledger。
4. 不确定项必须进入 Gap List。
5. 关键决策必须进入 Decision Log。
6. 每个阶段结束后必须等待用户确认。
7. 如果要新增独立新任务，必须先询问用户确认，不能自行新开任务台账。

## 启动口令

用户只需要说：

```text
开始任务：XXX
```

或：

```text
启动任务：XXX
```

GPT 应按以下流程执行：

```text
理解目标
→ 判断任务类型
→ 选择 Workflow Profile
→ 生成 Task Ledger
→ 分配 Agent
→ 生成 Context Pack
→ 逐步执行任务
→ 每步回填
→ 阶段结束等待用户确认
```

## 常用口令

| 口令 | 用途 |
|---|---|
| 开始任务 / 启动任务 | 启动当前任务台账 |
| 继续任务 | 继续当前任务台账 |
| 变更任务 | 修改当前任务范围、任务、输出物 |
| 关闭任务 | 完成、归档、复盘当前任务 |

## 文件说明

| 文件 | 作用 |
|---|---|
| `task-ledger-template.md` | 任务台账模板，唯一真相 |
| `agent-roles.md` | 通用 Agent 角色定义 |
| `context-packs.md` | 上下文包规则 |
| `change-request-template.md` | 任务变更模板 |
| `workflow-profiles.md` | 不同任务类型的执行流程 |

## 新增独立任务规则

如果用户只是继续当前目标，应该在当前 Task Ledger 里追加阶段或任务。

如果目标已经变成一个独立新任务，GPT 必须先询问用户：

```text
这看起来是一个独立新任务。是否确认新开一个任务台账？
```

用户确认后，才能新建独立 Task Ledger。
